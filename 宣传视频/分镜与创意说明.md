# Layerive｜少写提示词，让改图更简单

最后更新：2026-10-03。

新版工程：138 秒（2 分 18 秒）/ 1920 × 1080 / 30 fps / 中文大字幕 / 原创合成电子配乐 / 无配音。

本说明已落实到 `Layerive-Remotion-138s/` 新版工程，主合成 `LayerivePromo` 为 4140 帧。当前目录中的 `演示视频.mp4` 与 `Layerive-Remotion工程.zip` 保留为原 60 秒历史版本；新版通过 Remotion Studio 预览，源码归档为 `Layerive-Remotion工程-138s.zip`。

## 核心表达

用对话进行图片修改时，用户往往需要详细描述修改对象、所在位置、新内容，以及哪些部分必须保留。修改图片文字，还要解释原文字是什么、位于哪里、应该替换成什么；结果不符合预期时，又要补充说明、调整提示词、反复尝试。

Layerive 将这些编辑意图转化为直观操作：选择功能、圈出目标、填写新文字、选择参考图片，或将参考图拖到主图上。由视觉模型理解目标并组织编辑指令，减少用户描述位置、解释外观和反复编写约束的负担。

视频以“表达与反复尝试的痛点 → 直接操作 → 逐项功能演示 → 开源与模型自主接入”展开。删除元素连续展示海报船只和人物帽子两个案例，随后展示改字、提取素材、参考图局部替换、融合换装与变量批量制作。每段留出输入、操作与结果的阅读时间，让观众看清交互方式和真实变化。

删除元素的默认框选模式无需手写删除提示词；改字直接填写新文案；参考图局部替换可用图片表达内容，补充要求可以留空；换装用参考图与落点表达造型和目标。纯文字局部修改及其他需要说明的任务仍允许填写文字要求。“快速”主要表达操作与准备过程更直接，不承诺模型响应时间或一次生成必然成功。

## 开场痛点文案

第一条对话示意对应后面的船只删除案例：

> 删除河面中央的白色游船，保留大桥、岸边建筑和其他元素，补全被遮挡的水面，保持原有手绘风格、颜色和构图。

再依次追加两条补充说明：

> 只删除这艘船，其他区域保持不变。
>
> 修复的位置需要与周围水面自然衔接。

改字痛点对应后面的真实海报案例：

> 将海报上方的“十一上海”改成“国庆上海”，保持原有字体风格、颜色和排版，下方“旅行指南”不变。

每次只强调一组信息：目标、位置、保留要求、继续修改。完整提示词作为背景内容，不要求观众在短时间内逐字读完。以这些具体表达负担引出项目，避免暗示所有对话工具都无法完成相同任务。

## 节奏与视觉原则

- 沿用深色背景、紫色与青绿色强调、中文大字幕、真实作品与前后对比。
- 每段遵循“看清输入 → 看清操作 → 看清结果”；操作约 4–6 秒，重点结果约 4 秒，具体按段落长度分配。
- 每个时刻只突出一个阅读重点：操作时降低说明文字的视觉强调，结果阶段再出现价值句。
- 放大文字表单、人物头部和删除目标，避免观众在完整页面中寻找关键变化；前后对比保持主体位置与尺度一致。
- 原四张动作卡片不再单独占一段，其信息融入项目引入与对应案例。
- 延长现有场景时同步调整鼠标、选区、字幕与结果出现的时间，不只延长场景尾部。
- 换装作为融合的主要真实演示；独立的基础融合结果展示需有对应真实素材。当前描述的双图操作为主图加一张参考图，不表达任意多图同时融合的承诺。

## 素材与功能依据

- 作品、编辑表单与前后结果复用原工程中的真实截图裁切素材，以及 `layerive页面截图/` 中提供的原始截图。只做裁切、布局、放大与动画，不再生成或润色模型结果。
- 原工程包含未进入 60 秒成片的 `src/scenes/Extract.tsx` 和公交车素材，可复用为提取章节；帽子删除章节使用上述三张截图新增。
- 鼠标、拖拽、选区与开场对话气泡为编排的操作示意。生成等待经过剪辑，不代表真实模型响应速度。
- 演示能力对应当前应用中的框选删除、文字编辑、素材提取、参考图局部替换、融合换装、变量批量与模型配置。
- 项目地址：https://github.com/newljs/Layerive；主项目许可为 LGPL-3.0-or-later。
- 本地部署指工作台与项目数据位于用户电脑。模型请求发送至用户配置的模型服务，不宣称必然离线推理。
- 模型自主接入以接口兼容与模型能力为前提：图片接口覆盖 OpenAI Images、Gemini Interactions、Grok Images，并支持日日新适配；视觉接口支持 Anthropic Messages、Chat Completions、Responses。具体操作依赖相应模型能力。
- 新版配乐由工程内的 `scripts/make-soundtrack.py` 合成，无第三方录音采样；已扩展至 138 秒，48 kHz 立体声，使用 FFmpeg loudnorm 按 -17 LUFS 目标制作母带，章节进入时加入轻量提示音，结尾渐弱。
- 视频工程与应用源码分开维护；制作不访问真实模型密钥。

## 编辑和复用

新版位于 `Layerive-Remotion-138s/`，`src/scenes/` 为分镜组件，`src/LayerivePromo.tsx` 为总时间线，`src/Root.tsx` 为合成注册。11 个章节均已注册为独立可编辑合成，合成时长已计入 12 帧交叠转场。`scripts/prepare-hat-assets.py` 记录帽子截图裁切来源与坐标；已生成素材随工程打包，预览不需要重新裁切。

在新版工程目录中执行 `npm ci` 安装依赖，`npm run dev -- --no-open` 打开 Remotion Studio，选择 `LayerivePromo`。

`npm run lint` 检查类型，`npm run build` 构建预览包；需要 MP4 时可用 `npx remotion render LayerivePromo output/Layerive-少写提示词-138s.mp4 --codec=h264 --crf=18` 导出。`python scripts/package-source.py` 打包新版源码。

中文字体采用 Windows Microsoft YaHei；换系统渲染前需检查字体与换行。
